# Business Dashboard

Dashboard SaaS premium desenvolvido com HTML5, CSS3 e JavaScript, com métricas em tempo real, gestão de faturamento, atividades recentes e configuração de webhooks.

🔗 **Acesse:** [diovannymartins.github.io/business-dashboard](https://diovannymartins.github.io/business-dashboard/)

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades

- **Menu mobile responsivo**
- **Busca com atalho de teclado** (`Ctrl+K` / `⌘K`)
- **Cards de métricas** (MRR, usuários ativos, taxa de conversão)
- **Gráfico de barras dinâmico**, gerado a partir de dados em JavaScript, com tooltip ao passar o mouse
- **Tabela de faturas** renderizada dinamicamente, com persistência via `localStorage`
- **Feed de atividades recentes** dinâmico
- **Dropdown de seleção de workspace**
- **Dropdown de perfil do usuário**
- **Modal de configuração de webhook**
- **Totalmente responsivo** (desktop, tablet e mobile)

## ♿ Acessibilidade

- Contraste de cores adequado em todos os textos
- Labels associados aos campos de formulário
- Navegação por teclado nos elementos interativos
- `aria-label` em botões de ícone
