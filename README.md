# Business Dashboard

Dashboard corporativo desenvolvido com HTML e CSS, com foco em visual profissional e organização de informações.

## 🚀 Tecnologias
- HTML5
- CSS3

## 📊 Funcionalidades
- Painel administrativo
- Cards de métricas
- Sidebar de navegação
- Layout responsivo
